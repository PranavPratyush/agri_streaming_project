# Infrastructure — Grafana Dashboards

**Module:** `infra/grafana`  
**Purpose:** Pre-provisioned dashboards and datasources for operations and engineering research.  
**Scheduled Stage:** Stage 14  

## Planned Dashboards
1. **Field Telemetry & Ingestion:** Ingestion rates, sensor value trends, missingness indicators.
2. **Streaming Pipeline Health:** Micro-batch processing duration, consumer lag, checkpoint size, watermark lag.
3. **Agent & Triage Operations:** Alert classification distribution, grounding rates, LLM response latency, token cost.
4. **Resilience & Cluster Health:** Broker leader election state, DLQ volume, broker kill recovery metrics.
