# Experiments & Benchmark Results

**Directory:** `docs/experiments`  
**Purpose:** Formal experiment plans, parameter logs, and empirical benchmark outputs for the IEEE technical paper.  
**Scheduled Stage:** Stage 20 & Stage 21  

## Experiments
1. `01_detector_comparison.md`: Evaluation of EWMA, rolling Z-score, and windowed Isolation Forest.
2. `02_agentic_triage.md`: Comparison of B1 (rules), B2 (single LLM+RAG), and B3 (bounded investigator agent).
3. `03_fault_tolerance.md`: Chaos engineering drills (MTTR, message loss, duplicate actions).
4. `04_scalability.md`: Throughput and P99 latency across varying partitions and field counts.
