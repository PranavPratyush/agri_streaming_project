# Farmer PWA (Progressive Web Application)

**Module:** `apps/farmer-pwa`  
**Purpose:** Mobile-first, responsive, field-accessible progressive web application for farmers.  
**Scheduled Stage:** Stage 18  

## Capabilities
- Field registration and profile management (crop, sowing date, growth stage, soil type, sensor depth).
- Real-time field status and sensor data freshness.
- Plain-language alert notifications with transparent evidence and source citations.
- One-tap recommendation approval or rejection.
- Alert history and audit log.
- Multi-lingual UI support (English + Kannada).
