# Injected Scenarios & Evaluation Labels

**Directory:** `data/scenarios`  
**Purpose:** Ground-truth manifests and parameters for ~60 labeled fault and stress injection scenarios.  
**Scheduled Stage:** Stage 9  

## Scenario Types
- **Sensor Faults (20):** Stuck values, sudden spikes, calibrated drift, dropouts, implausible readings.
- **Crop Stress (30):** Drought dry-down, extreme heat stress, high-humidity/disease-risk windows.
- **Transient Noise (10):** Natural micro-fluctuations and weather anomalies that should NOT trigger alerts.
