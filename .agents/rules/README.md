# Antigravity Project Rules

**Directory:** `.agents/rules`  
**Purpose:** Version-controlled rules governing Google Antigravity behavior across this repository.  
**Scheduled Stage:** Stage 4  

## Planned Project Rules
1. `architecture-guardrails.md`: Kafka event backbone, Spark streaming, selective LLM triage, no raw reading LLM calls.
2. `data-provenance.md`: Source labeling, unit tracking, no conflating reanalysis with physical probes.
3. `agronomic-safety.md`: No unsupported disease diagnosis, no pesticide dosages, no autonomous physical actuation.
4. `security-and-secrets.md`: No committed credentials, local service binding, least privilege.
5. `testing-and-evaluation.md`: Verification before completion, no fabricated metrics, reproducibility.
